# KaifDesktop — Кайфик

Локальный настольный питомец для Windows. Для запуска откройте `actual/KaifDesktop.exe`. Интернет и ChatGPT во время работы не требуются.

## Структура

```text
KaifDesktop/
  actual/                 текущая версия: Alpha-drag
  backup/version1/        предыдущая версия: Alpha-petting
  docs/                   документация разработки и планы
  devs/                   исходники, мастер-графика и инструменты
  README.md               этот файл
```

В каждой версии находятся `KaifDesktop.exe`, `Frames/`, `memes/`, `data/`, `Decription.md` и `tests/`. Инструкция к текущей версии: [actual/Decription.md](actual/Decription.md). Мемы ищутся в `memes/` относительно папки EXE: переносите всю папку приложения, а не один EXE. Настройки и журналы находятся в `data/` рядом с приложением; папка должна быть доступна для записи.

`actual` поддерживает перетаскивание; предыдущая Alpha-petting — поглаживание без добавленного позднее drag. Исходные EXE сохранены без пересборки. Известная жалоба на свёрнутые окна мемов пока не исправлена.

## Для разработки

Начните с [docs/PROGRESS.md](docs/PROGRESS.md). Код — `devs/src/`, решение — `devs/KaifDesktop.sln`, сборка — `devs/build.ps1`, исходные кадры — `devs/Frames/`, мастерская графики — `devs/work/`.

Перед согласованным этапом изменений actual сохраняется в backup/version1. Прежний backup временно хранится в version2 до одобрения этапа. Обычная повторная сборка не должна заменять резервную копию. Исторические пути в старых отчётах оставлены как свидетельства прежних проверок; они не являются текущими командами запуска.
