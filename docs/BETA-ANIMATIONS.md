## Дополнительные задачи беты

1. Дорисовать недостающие ракурсы ХОДЬБЫ для всех 8 направлений движения.
2. Дорисовать недостающие ракурсы БЕГА для всех 8 направлений движения.
3. Отдельная задача кода: подключить все 8 направлений ходьбы и все 8 направлений бега к выбору анимации по вектору движения, включая диагонали.

Всего целевой набор — 8 направлений шага и 8 направлений бега. Имеющиеся боковые ракурсы использовать с учётом решений выше; не перерисовывать все автоматически. Восемь направлений движения: вверх, вверх-вправо, вправо, вниз-вправо, вниз, вниз-влево, влево, вверх-влево.

Прежняя задача «хождение на задних лапах» уточнена пользователем: относится к дефекту задних лап медленного шага, уже включённому в walk-left/right; отдельную дублирующую работу не создавать.

Исходные jumping/failed пока не удалены. Этот документ фиксирует исключение из будущего игрового состава, а не поручение на удаление файлов.
